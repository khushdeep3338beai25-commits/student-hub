# 🎓 EduSphere - Student Management System

A modern and responsive **Student Management System** developed using **Node.js, Express.js, MongoDB, HTML, CSS, Bootstrap, and JavaScript**. This application helps manage student records with an intuitive dashboard and complete CRUD functionality.

---

## ✨ Features

- ➕ Add New Student
- ✏️ Update Student Information
- 🗑️ Delete Student Records
- 👀 View Student Details
- 💾 MongoDB Database Integration
- 📱 Responsive Bootstrap UI
- 🎨 Modern Dashboard Design
- ⚡ Fast CRUD Operations
- 🔒 Server-side Data Handling

---

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/your-username/student-management-system.git
```

### Go to project directory

```bash
cd student-management-system
```

### Install dependencies

```bash
npm install
```

### Create a `.env` file

```env
MONGODB_URI=your_mongodb_connection_string
PORT=3000
```

### Start the server

```bash
npm start
```

Open your browser and visit:

```
http://localhost:3000
```
